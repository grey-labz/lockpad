# Approved material: idea → build → working demo

The user chose a narrated walkthrough and revised Lockpad to offer immediate funded-pool borrowing or a marketplace sale if the quote is unsuitable. The user supplied the black-and-green palette. This two-minute film follows those choices using real app footage.

One local reference payout NFT travels through Alice's 650 TUSD loan, 663 repayment and recovery of collateral; Alice then selects the 920 TUSD sale alternative, Bob receives the NFT, Alice withdraws the sale proceeds, and Bob claims 1,000 at its original maturity. Receipts close the walkthrough.

The scene script is in narration-borrow.json. capture-borrow.mjs records actual app actions and asserts authoritative contract state and token transfers. Local Sandbox time advances only after the sale; the film explicitly labels that advance and preserves the original maturity. Every scene displays LOCAL NEAR SANDBOX · ZERO-VALUE TUSD.

The four contracts are a fixed-payout reference source, funded lending pool, marketplace and test token. External DEX adapters and production valuation are proposed work before mainnet. The user will publish the X post and enter personal submission fields.
